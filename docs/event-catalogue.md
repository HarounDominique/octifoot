# Event catalogue

What octifoot does with each of the 172 event types SpiderFoot v4.0 can emit, and why. Generated by
`connector/tools/build_catalogue.py` from SpiderFoot's event-type table, its module metadata, counts of what
21 real passive scans of 3 domains produced, and the decisions in `catalogue.py`; tests fail if this
page drifts from the mapper. Do not edit it by hand.

Only **46** of the 172 types appeared in those scans: the passive, keyless configuration produces a small
part of what SpiderFoot can find. Most of the rest needs an API key or an active module.

| Status | Types | Meaning |
|---|---|---|
| imported | 17 | the mapper turns it into an object, label or Note line today |
| planned | 1 | seen in real scans and worth importing; a named slice will do it |
| declined | 42 | decided against, with the reason (mostly: it describes a third party or is raw text) |
| blocked | 34 | not produced by this configuration: needs an API key or an active module |
| no-data | 78 | producible with the current profile but never seen; decide when real data exists |
